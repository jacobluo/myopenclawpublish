来源账号：Jim Fan（DrJimFan）/ X 登录态核验

发布时间：2026-06-17 · X 帖子 · 项目页

Jim Fan 发布 ENPIRE：给 8 个 Codex agents 一组机器人、GPU 和 token budget，让它们在真实物理任务里搜索文献、实现想法、运行实验并保持机器人忙碌。它的重点不只是“机器人 + LLM”，而是把 agent 的研究循环接到物理执行环境。
