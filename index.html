Anthropic 如何解决代码评审：Claude Code 团队的七层防线（中文译文 + 总结）

翻译 Anthropic 官方博客《How the Claude Code team does code review》：Claude 团队没有取消代码评审，而是把'读代码'从人转移到机器，围绕人类时间与注意力做优化。6—9 月合并 PR 翻倍、回滚率降 40%+，靠的是七层防线（PR 前验证、每个 PR 的 AI 评审、可阻塞的安全评审、自动化检查、按风险分级的人工批准、合并队列+flag、快速回滚），以及用事故当 eval、强制评审收敛、度量噪音让评审器持续变好。附原文与总结。
