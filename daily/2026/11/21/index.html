总览

今天最值得关注的不是又一个通用排名，而是两条成本曲线：让小模型在真实 Agent 环境中完成更多工作，以及让科研成果获得可信验收所需的成本。Thinking Machines 发布面向本地部署的循环 Transformer；Hugging Face 将模型、任务与 harness 联合优化推进到可复用训练配方。另一边，Claude 参与黎曼猜想证明的声明迅速传播，但“作者称已完成形式化”与“第三方审查确认”仍是两件事。

核心主题

1. 小模型竞争从参数量转向“完成任务的整套系统”

循环计算将更多推理留在内部层，harness adapter 则让模型学会当前工具环境的操作习惯。共同趋势是减少无效生成、重复工具调用和人工返工；但更少输出 token 不等于更少总计算，本地推理也需计入内存、速度、设备与维护。创业和投资研究可重点观察低成本常驻工作负载，而非仅跟踪模型下载量。

2. AI 科研的竞争单位是“主张—证据—审查—实验”链条

数学声明需要检查精确命题、形式化依赖和独立重放；药物研究则需要实验、候选物推进和临床证据。今天的数学讨论与 MedChemBench 正好构成对照：形式化文件和基准分数都可以提供证据，却不能越过其验证范围直接宣布科学问题已解决或药物已发现。

3. 常驻 Agent 必须同时具备治理与商业边界

Harrison 关于计划触发 Agent 的观察，与 ChatPRD 的试用滥用案例说明：无人值守的执行能力既是价值，也会变成算力成本入口。编辑判断：产品护城河更可能来自可追溯任务、业务定义、额度治理与可靠交付，而不是把通用代理接到无限试用入口。

重要更新

1. Inkling 2 Mini：26.4B 开放权重循环模型，瞄准本地 Agent

Mira Murati @miramurati；Clem @ClementDelangue / Thinking Machines、Hugging Face · 11-21 04:14、04:17；模型发布日期 11-20
Mira 原帖 · 发布说明 · 权重与模型卡

摘要：官方发布的 Inkling 2 Mini 为 26.4B 总参数、3.4B 激活参数的多模态 MoE，24 层中间 12 层循环三次，每 token 折算 5.4B 权重激活。模型卡注明 Apache 2.0，混合 NVFP4/MXFP8 检查点约 20GB，支持的 Apple silicon 设备要求至少 32GB 内存；“能在笔记本运行”不是任意笔记本均可运行。厂商报告 DeepSWE v1.1 为 48.2%，同时承认多轮聊天、复杂约束及知识密集任务仍有短板；演示飞行模拟器的视频多数以 15 倍速播放。另发布可变循环研究模型，不能将其可变深度功能套到固定三轮的 Mini 上。

为什么值得看：本地持续运行、离线隐私和可定制工具链获得新候选；循环架构也让“读思维链就能监督推理”的假设需要重新检验。

后续行动：先核对设备与推理框架，再用固定仓库任务比较成功率、端到端时延、内存和能耗；将官方的可监控性实验视为当前规模下的初步证据，不外推为更大模型的安全保证。

2. Harness adapters：在部署时的真实工具循环里训练模型

Hugging Face；关联 Clem / Thomas Wolf 的开放生态跟踪 · 官方 RSS 标记 11-20 08:00（GMT 零点，可能为日期占位）
完整配方 · 适配器集合

摘要：团队分别在 pi、OpenCode 和 Hermes Agent 内，为 Qwen3.8-27B 训练 RL LoRA，冻结底座而非重训整个模型，并尝试合并为跨 harness 适配器。文章报告 pi 下 Terminal-Bench 2.1 从 39% 到 55% pass@1，平均 token 从 2.9K 到 1.5K；这是指定底座、任务和环境下的作者结果，不是所有 Agent 通用提升。训练配方强调排除评测集及同仓库任务，检查正确解、空操作与错误解，再选择基础模型有时能解、有时失败的题目。此次提供更大规模、多 harness 配方；不是把前几日已报的定向 RL 概念再包装成首次提出。

为什么值得看：价值不仅在 LoRA，还在可验证环境和难度筛选；奖励函数接受错误答案，会把错误行为强化得更高效。

后续行动：优先审查自身任务的 verifier，建立独立保留集后再训练；比较通过任务的总成本、跨仓库迁移和适配器切换后的退化，勿只优化 token 数。

3. Claude 与黎曼猜想：强声明已出现，定论尚未建立

Kevin Weil @kevinweil、Jim Fan @DrJimFan；Simon Willison；Levent Alpöge、Ravi Vakil · Kevin 11-20 23:18；Simon 两篇 11-21 00:30、03:21
传播线索 · Alpöge 四页声明 · Simon 引介 · Vakil 独立候选稿说明

摘要：Alpöge 在本人 PDF 中称与 Claude 找到 RH 及 GRH 的证明、已无假设形式化，并给出分卷 Lean 文件；本轮已提取并阅读这份四页说明，但未下载和编译庞大证明工程。Kevin 与 Jim Fan 的反应扩大了传播，其中 Jim 明确保留“希望是真的”的条件。Ravi Vakil 同日另介绍 Alessandro Masullo 的人类独立 GRH 候选证明，称 Brian Conrad 已长期阅读反馈，仍希望同行检查和补足细节。这是两条不同的候选证明路线，不能混为 Claude 成果，也不能从任何一方的信心推断数学界已确认。

为什么值得看：若经确认将是重大科学事件；目前最有价值的工作是复核命题与依赖，而不是根据社交热度判定“AI 已解决”。

后续行动：跟进独立数学家审查、Lean 可重放结果、所用公理与目标命题对应关系；确认项目版本与可理解证明。作者声称无假设不等于本报已验证无额外公理或形式化缺口。

4. MedChemBench：测药物化学推理，不能替代新药实验

Greg Brockman @gdb / OpenAI · 11-21 03:22；官方发布日期 11-20
Greg 原帖 · 官方研究说明

摘要：MedChemBench 从 117 篇论文和专利构建 99 个问题、761 种分子结构，测结构重建、科学解释、排序选择和性质预测。官方报告 xhigh 下 GPT‑6.2 Astra 获可得分数的 84.5%，GPT‑6 Astra 为 83.3%；后者结构重建明显强于候选选择及数值预测，不能将总分解释为药物发现成功率。作者明确无法排除历史材料暴露，每题单次作答且无工具、反馈或新实验，因此结果未证明能改善真实实验室决策。同窗口 Greg 另转述神经退行性疾病合作线索，本轮未核读完整研究，不和该基准合并为临床成果。

为什么值得看：结构正确不等于性质预测正确，分项成绩比“大模型懂化学”的总叙述更适合指导科研辅助工具。

后续行动：跟进未公开新数据的前瞻性验证、药化专家盲评与真实实验；投资研究区分基准成绩、合作合同、候选物进入试验和临床疗效四个阶段。

5. 从试用滥用到对抗蒸馏：AI 产品要守住算力与数据边界

Simon Willison 引介 Claire Vo / ChatPRD；OpenAI 官方补充 · Simon 11-20 10:49；OpenAI RSS 11-20 18:00
Simon 文章 · Claire 视频线索 · OpenAI 防护说明

摘要：Simon 介绍 Claire Vo 报告的 ChatPRD 试用滥用：批量试用和优惠码被当作通用算力入口，用于其他商业工作，并称她正取消免费试用；本轮读的是 Simon 的文字介绍，未观看完整视频，也不把较早的视频当作今天刚发生的事件。OpenAI 同日说明请求级防护与跨账号活动检测，报告自有自适应测试中先前请求的受保护推理提取成功率由 54.0% 降至 0.2%。两者是不同事件：产品额度套利不能自动等同于模型蒸馏，厂商内部攻击测试也不是线上永不泄漏的保证。

为什么值得看：Agent 若能自由调用工具，产品的试用预算就可能变成可转售资源；应同时测业务价值与异常成本，而不只统计注册增长。

后续行动：对试用设总预算、工具范围、异常用量监测与人工复核；保留合法用户申诉路径。涉及第三方归属与国家安全的厂商指控不在未独立核验时扩写成结论。

6. 常驻 Agent：计划触发增加，但“多数”并非行业普查

Harrison Chase @hwchase17；Hamel Husain @HamelHusain · 11-21 02:59、01:08
计划触发讨论 · 本周工具与治理回顾 · Hamel 的 evals 观点

摘要：Harrison 称多数 Agent run 已非人工触发，所引讨论观察部署中的调度触发占比增长，但未提供可供本报审计的总体样本。其本周回顾列出 Tool Gateway、编码 Agent 成本观察与 trace 权限，是多天发布的汇总，不重复算今天新功能。Hamel 强调 evals 中好的流程比工具重要，这与常驻任务需要明确定义验收的方向一致，而非一个新评测产品发布。

为什么值得看：主动执行的产品价值在于正确时机完成可验收的事情；触发次数多本身不证明用户价值或收入。

后续行动：为定时任务设置幂等键、重试预算、证据保留和失败通知；记录“被发现的有效信息”和“已完成交付”，不要用执行量替代成功率。
