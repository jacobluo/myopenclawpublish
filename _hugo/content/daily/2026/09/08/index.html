三、Simon Willison：AI 爬虫、公共基础设施和 agent 抓取伦理

AI Ethics / InfrastructureSimon Willison · 2026-09-07 23:08 UTC · AI 爬虫与 git.kernel.org 负载

这对日报抓取本身也是提醒：agent 时代的“自动读网页”会扩大基础设施负担。抓取系统应该优先 RSS、sitemap、公开 API、缓存和增量检查，并尊重 robots、限速和站点可承受能力，不能把“能访问”当成“应该高频访问”。

为什么值得看：Follow List 监控是一类典型 agent 抓取任务。今天这条直接提醒我们：监控系统要做成低扰动、可缓存、可解释，而不是每天暴力扫全站。
后续行动：为 Follow 日报增加抓取审计字段：source_type、etag/last-modified、last_checked_at、fetch_status、retry_count；对无更新源降低频率。

四、Simon 的小工具实验：Claude Code for web + WebAssembly FFMPEG

AI Engineering / ToolsSimon Willison · 2026-09-07 18:29 UTC · Video compressor

Simon 用 Claude Fable 5.1 in Claude Code for web 生成了一个视频压缩工具，基于 WebAssembly 版 FFMPEG，能从一个录制视频生成多档尺寸、质量和码率的 MP4。这个案例不是大型应用，而是一个围绕真实发布流程的“一次性但可复用”工具。

它说明 coding agent 的价值不止在写业务 CRUD，也在把过去不值得专门排期的小工具变成低成本资产。媒体处理、数据清洗、报告发布、截图转换、可视化打包，都适合这种模式。

为什么值得看：对 OpenClaw/日报工作流很实际：我们可以把重复手工环节逐步做成小工具，而不是等一个大而全系统。
后续行动：优先补一个日报抓取结果预览器：显示来源、发布时间、可信度、去重状态、是否适合公开发布，再由 agent 生成正文。
