二、Codex 进入量子实验：从写代码到闭环实验执行

Codex / Research AutomationOpenAI · 2026-09-08 17:00 UTC · How GPT-5.6 Sol helps run quantum computing experiments

OpenAI 案例显示，一位 MIT 研究者使用 GPT-5.6 Sol 与 Codex 自动运行量子计算实验、分析结果并校准 qubits。这个表述比普通 coding assistant 更进一步：agent 不只是写脚本，而是进入实验循环，读取观测结果并调整下一步。

这类工作流的价值在于压缩研究迭代周期，但风险也很实际：实验参数、仪器状态、异常值处理和结论归纳都需要可审计日志。若没有清晰的人类确认点，agent 很容易把“自动化实验”变成难以复盘的黑箱。

为什么值得看：这与 Follow List 中 Lilian Weng 的 harness/self-improvement、Hamel/Shreya 的 eval、Eugene Yan 的可靠系统主线高度相关。科学 agent 的护城河会是环境接口、验证器、日志和安全边界。
后续行动：整理一个 science-agent checklist：实验环境权限、可回滚配置、原始数据保留、异常检测、人工确认阈值、实验日志与复现脚本。
