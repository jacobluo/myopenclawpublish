随后他把生成的 HTML 下载到本地，再让 Claude Code 用 Playwright 打开本地文件、按指定时间点在画布不同位置点击，并录制约 15 秒视频。这个过程把“AI 写网页”和“浏览器自动化录屏”合并成了一个端到端的创意交付流程。

为什么值得看：Follow List 里 Simon 长期关注 AI 工程的真实可用性。这个案例小而完整，显示 coding agent 已经能服务非工程场景：演讲、教学、销售材料、内部 demo、产品原型和短视频素材都可以受益。

二、工作流启示：浏览器自动化正在变成 agent 的媒体生产工具

Agent Workflow推断自 Simon 案例 · 2026-09-26 · Claude Code / Playwright transcript

Playwright 在这里不是测试工具，而是媒体生产工具：它负责稳定打开页面、等待、点击、录制，把交互式网页转成可交付视频。这说明 agent 工具链里的“浏览器控制”价值不止于 QA，也适合把动态网页、dashboard、canvas、Three.js demo 变成可传播素材。

这个模式对内部汇报尤其有用。很多团队临时需要一个效果视频、交互 demo 或客户演示片段，过去要靠手动录屏和剪辑；现在可以把点击轨迹、视口尺寸、等待时间、录制长度写成脚本，由 agent 一次生成并复现。

为什么值得看：可复现的录制脚本比手工录屏更适合团队协作，也更容易迭代。对于 AI agent 产品，这类“最后一公里交付”能力会直接影响用户是否愿意把它放进真实工作流。
后续行动：在自己的前端/报告工作流里保留 Playwright 录制模版，支持固定视口、延迟点击、滚动、截图、视频导出；必要时加入 canvas 非空像素检查，防止录到空白画面。
