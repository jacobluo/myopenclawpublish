总览

GPT-6.1 Terra：OpenAI 补上「成本-智能」低价档，Terra/Sol/Astra 三层定价成型

OpenAI 发布 GPT-6.1 Terra，定位「视觉推理 + 精确计算机使用 + 自然写作」的快速低价模型：标准 API 定价 $5/1M 输入、$25/1M 输出（比 GPT-5.6 Terra 降 50%），代理速度约 3 倍，Terminal-Bench 4.0 从 21.5% 翻倍至 50.3%；同日进入 GitHub Copilot。官方明确「复杂编码/深度研究仍用 Sol 或 Astra」，等于把三条产品线各就其位。

Anthropic 递交 S-1，IPO 从「传闻」变「流程」

Anthropic 于 10-26 向 SEC 递交 S-1 注册声明，正式启动上市流程。这直接衔接 10-15 那则「季度营收近 50% 增速、$16.8B」的上市前披露——现在有了可查证的官方动作，而非仅媒体转述。

前沿模型开始「碰」开放数学与物理难题

OpenAI 发布「与学术界共建科学理解」，披露模型在 Kakeya 猜想、指数时间假设（ETH）、量子色动力学（QCD） 上的结果，并给出学术界如何验证与在之上构建的机制。这是继早前「Sol Ultra 数学证明」之后，官方再次把前沿模型摆进开放科研的位置。

核心主题

一、GPT-6.1 Terra：OpenAI 的「成本-智能」低价档，且同日打通 GitHub Copilot 分发

前沿模型 / 定价策略 / AI 编程代理OpenAI（官方） · 2026-10-26 · Introducing GPT-6.1 Terra / API 模型页 / 系统卡补充页 / GitHub Changelog：GPT-6.1 Terra in GitHub Copilot

GPT-6.1 Terra 是 OpenAI 在 10-26 发布的新一代「快速、高效」档模型，主打三类能力：视觉推理、精确的计算机使用（computer use）、清晰自然的写作。关键数字：标准 API 定价 $5/1M 输入、$0.50/1M 缓存输入、$25/1M 输出——比 GPT-5.6 Terra 的标准化定价整体低约 50%；OpenAI 官方口径是「代理速度约 3 倍」。基准上最突出的是 Terminal-Bench 4.0 拿到 50.3%（最大推理档），而上一代 GPT-5.6 Terra 仅 21.5%，即翻倍还多，说明这一档在「终端操作 + C# 类工程任务」上补课明显。

系统卡补充页给出两个值得注意的细节：一是 GPT-6.1 Terra 沿用 GPT-6 Astra 的训练数据与训练方式（即同一前沿基座家族派生出的低成本档，而非独立训练的小模型）；二是安全侧 ExploitBench 的 ACE 归一化均分为 97.10%——延续了近期「前沿模型即便低成本档也保有可观攻击性代码能力」这条被反复验证的观察。

分发的关键在于「同日进入 GitHub Copilot」：Changelog 明确 GPT-6.1 Terra 已 GA，定位「日常 agentic 编码 + 终端工作」，比 GPT-6.1 Sol 更便宜，早期测试中比 GPT-5.6 Terra 多解出不少终端与 C# 任务，「在收敛、合并步骤下处理边界清晰的任务」。计费走 usage-based 的 provider 目录价。

战略含义要放在整个模型家族里看：OpenAI 现在给出一条非常清晰的三层阶梯——Terra = 快/便宜/日常 agentic + 计算机使用；Sol = 复杂编码/深度研究；Astra = 前沿全能。官方在发布口径里反复说「复杂编码和深度研究请选 Sol 或 Astra」，这既是防误用的引导，也是一种「按工作量分级定价」的市场分层，与上一窗口 Kimi K3.1 Pro「$2/$10 激进定价」以及「2.8T MoE 部署成本 vs 定价」的争论形成对照。

为什么值得看：①这是 Follow List 上 Kevin Weil / Josh Woodward / Sam Altman 等 OpenAI 高优先人物的主场信号，且是「成本-智能前沿」（cost-intelligence frontier）这一 OpenAI 反复强调叙事的最新落地。②「同日进 Copilot」把模型发布和开发者分发直接打通，验证了上一窗口「Copilot 正在被重定位为『超越 IDE 的模型供应商』」的判断——现在 Copilot 就是 Terra 的第一个规模化分发渠道。③50% 降价 + Terminal-Bench 翻倍，是「推理成本下探 → 更便宜档也能做 agentic 终端工作」这条趋势的量化样本，对「AI 编程代理的单位经济」讨论有直接参考价值。

后续行动：跟踪 GPT-6.1 Terra 在 Copilot 的实际计费与用户迁移情况，以及它是否挤压 GPT-6.1 Sol 的中低价位；把「Terra/Sol/Astra 三层定价」与 Kimi K3.1 Pro、Claude Opus 5.5 的定价并案，做一张「前沿模型分层定价」对照表；关注 ExploitBench 97.10% 是否被安全圈引用，作为「低成本档网络能力不降反稳」的又一实证点。

二、Anthropic 递交 S-1：IPO 从传闻变成可查证流程

公司战略 / 资本市场Anthropic（官方 /news 页面） · 2026-10-26 · Anthropic Newsroom（条目：Anthropic files S-1 with the SEC for proposed initial public offering）

Anthropic 于 10-26 在官方 Newsroom 挂出「Anthropic files S-1 with the SEC for proposed initial public offering」（向 SEC 递交 S-1，拟进行首次公开募股）。这是继 10-15 Simon Willison 转引的「Anthropic 向投资人披露季度营收近 50% 增长、达 $16.8B，为 IPO 做准备」之后，第一次出现官方可查证的动作——从「媒体转述上市准备」升级为「S-1 注册声明进入 SEC 流程」。

需要克制的一点：S-1 的提交只是 IPO 流程的早期节点，不等于定价、路演或上市日期已定；且本窗口内 OpenClaw 无法稳定读取 Anthropic 该文章正文（/news RSS 仍 404，/news 页面可见条目标题与日期但正文为 JS 渲染），所以上面只取「已递交 S-1」这一可核验事实，不展开营收、股权、承销行等未经确认的细节。

为什么值得看：Anthropic 是 Follow List 里 Sam Altman 之外的「前沿实验室」核心观察对象，Alex Albert（Anthropic，高优先）与 Dario 相关信号长期在列。IPO 落地会把「AI 公司如何估值、如何向公开市场交代营收/毛利/安全投入」变成持续的公开数据源，也会反向影响「开源 vs 闭源」「安全 vs 商业化」的话语权重。对跟踪 AI 产业链与二级市场的人，这是一个新的、高价值的观测节点。

后续行动：在 SEC EDGAR 检索 Anthropic 的 S-1 原文（一旦公开可下载），提取营收结构、毛利、R&D/安全投入、客户集中度等关键指标；与 OpenAI 的融资/估值、以及「Anthropic Public Benefit Fund」的公司治理结构并案，观察 IPO 对「公益约束 vs 股东回报」叙事的影响。

三、前沿模型开始碰开放数学/物理：Kakeya 猜想、ETH、量子色动力学

AI for Science / 前沿研究OpenAI（官方） · 2026-10-26 · Working with academic communities to build scientific understanding

OpenAI 发布「与学术界共建科学理解」，披露模型在三个开放问题上的结果：Kakeya 猜想（调和分析经典问题）、指数时间假设（ETH，计算复杂度核心猜想）、以及量子色动力学（QCD），并说明学术界可以如何验证、以及如何在模型输出之上继续构建。RSS 摘要措辞克制：「OpenAI 分享模型在 Kakeya 猜想、指数时间假设与量子色动力学上的结果——以及研究者如何验证并在其上构建」。

这延续了更早窗口的一条暗线：从「Sol Ultra 64-subagent 数学证明信号」到现在的官方成体系发布，OpenAI 正把「前沿模型产出可被学术界验证的数学/物理进展」制度化为一种发布品类。与 DeepMind 侧的 AlphaProof/AlphaGenome 等「AI for Science」叙事形成对照：OpenAI 这里更强调「把结果交回学术共同体、并给出验证与复用机制」，而非单点夺旗。

为什么值得看：「模型能否在开放、可验证的硬问题上产出增量」是判断「推理能力是否真前沿」的少数干净试金石，比易被污染的私有基准可信得多。Kakeya 猜想与 ETH 都是业界公认的硬骨头，QCD 更是物理高能领域的核心。若这些结果能经得起同行复核，它对「AI 用于科研」的估值与叙事是实质利好；同时这也是 Follow List 里 Noam Brown（OpenAI 推理研究）、Demis Hassabis（DeepMind 科学/AI）两条高优先线的交叉点。

后续行动：等学术共同体对 Kakeya/ETH/QCD 结果的第三方复核与论文链接；把「OpenAI 学术发布」与「DeepMind AlphaProof/AlphaGenome」并案，跟踪「AI for Science」的发布节奏与可信度；若结果被同行引用，记为「前沿模型具备真实科研增量」的强证据。

四、AI for 网络安全主线延续：CodeRabbit、Greptile 两条案例 + ExploitBench 97.10%

AI 安全 / 代码安全 / 案例OpenAI（官方） · 2026-10-26 · GPT-6.1 Sol helps CodeRabbit strengthen security across complex codebases / Greptile takes bug detection beyond code review with GPT-6 Astra

两条官方案例，共同落在「用前沿模型做代码/基础设施安全」这条已经连续多窗口出现的主线（此前有 PHP2Shell、Patch the Planet、Cloudflare、SentinelOne/Block 等）。

①CodeRabbit：用 GPT-6.1 Sol 在复杂代码库中调查安全风险，其「安全 agent」帮助开发者复核发现的问题与建议的修复——把「漏洞发现」往下游推到「修复建议的复核」。

②Greptile：用 GPT-6 Astra 把「bug 检测」延伸到 code review 之外——「测试用户工作流、用 Daybreak 强化安全、用 Codex 减少返工」。注意这里 Daybreak（OpenAI 的网络防御/红队线）与 Codex（编码 agent）被组合进同一客户工作流，是「模型矩阵协同」的样本。

叠加第一条 GPT-6.1 Terra 系统卡补充页的 ExploitBench ACE 归一化 97.10%，这条主线在本窗口的图景是：低成本档仍保有可观的攻击性代码能力，而同一批能力正在被官方打包成「安全 agent / 漏洞检测 / 修复复核」卖给防御方——「红队能力」与「防御产品」用的是同一套模型能力。

为什么值得看：这是「AI 双重用途」最清晰的商业呈现：攻击面（ExploitBench 97.10%）与防御面（CodeRabbit/Greptile）由同一模型家族同时供给。它直接回应上一窗口 Interconnects 抛出的「开放权重 + 网络安全是不是判断错了」——闭源前沿实验室正在把「网络能力」做成可采购的防御产品线，而开放权重侧则面临「消融模型商品化」。对跟踪「AI + 网络安全」生态的人，这是判断「能力扩散速度」和「防御商业化」两端的关键样本。

后续行动：把 CodeRabbit/Greptile 纳入「AI 安全 agent 商业化」案例库，与 Cloudflare、SentinelOne、Block 并案；持续跟踪 ExploitBench / Cyber 类公开榜上「低成本档」的能力曲线，作为「模型成本下探是否同步带来攻击门槛下探」的量化指标。

五、ChatGPT 的「工作世界」扩张：OpenAI Signals 165 项工作活动、近 100 国

AI 采用 / 劳动力市场OpenAI（官方） · 2026-10-26 · ChatGPT's expanding world of work

OpenAI 发布「ChatGPT 的扩张中的工作世界」，基于 OpenAI Signals 数据：覆盖近 100 个国家的 165 项工作活动，展示人们如何用 ChatGPT 处理工作、以及这些用途如何随时间变化。这是继「ChatGPT Work 向 Uber 3 万员工铺开」等案例之后，一次偏宏观的采用数据披露，把「AI 如何进入具体工作活动」量化到 165 项活动的粒度。

为什么值得看：它承接了上一窗口 Anthropic「How employment is changing at Anthropic」这条「AI 与就业结构」主线，但把视角从「一家实验室的内部就业」拉到「近 100 国的采用分布」。对跟踪「AI 采用率 / 工作替代与增强」的人，165 项工作活动的明细是可做纵向对比的公开数据点（未来可观察哪些活动被 agent 化、哪些被保留）。

后续行动：待该页可稳定抓取后，提取 165 项工作活动的分类与国别分布，与 Anthropic 就业文、以及「ambient agents / 定时调度」的 LangChain 框架交叉，判断哪些工作活动正在从「人主动调用」转向「agent 自动执行」。
