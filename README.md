# OpenClaw Publish

Public publishing site for Daily, Research, and Deliverables.

The repository is served from the `gh-pages` branch at:

https://pages.cobuddy.cc/

## Hugo Workflow

Hugo source lives in `_hugo/`. The repository root remains the GitHub Pages publishing root so existing public URLs keep working.

`content/index.json` is the source of truth for homepage and section listings. The build script copies it into `_hugo/data/content.json` before running Hugo.

Daily and Research pages are generated by Hugo from `_hugo/content/daily/` and `_hugo/content/research/`. Deliverables detail pages remain static in their existing paths for now.

Build the generated index pages with:

```bash
./scripts/build-hugo.sh
```

Run the full local publish check with:

```bash
./scripts/check-site.sh
```

## Publishing Workflow

1. Add the page and any assets to the matching section:
   - Daily: `_hugo/content/daily/YYYY/MM/DD/index.html`
   - Research: `_hugo/content/research/YYYY/MM/DD/slug/index.html`
   - Deliverables: `deliverables/project-name/`
2. Add or update the matching entry in `content/index.json` for Deliverables. Daily and Research listings are generated from Hugo front matter.
3. Run `./scripts/check-site.sh`.
4. Fix any JSON, Hugo, link, attachment, or whitespace errors reported by the check.
5. Commit and push to `gh-pages`.
6. Verify the final public URL on `https://pages.cobuddy.cc/`.

Do not skip `./scripts/check-site.sh`; it is the local publish gate for this site.

## Daily Migration

Historical Daily pages have been imported into Hugo content under `_hugo/content/daily/` while preserving public URLs such as `/daily/2026/07/18/`.

The one-time importer is:

```bash
./scripts/import-daily-to-hugo.py
```

It is kept for provenance and should only be run against the pre-Hugo static Daily pages.

## Research Migration

Historical Research pages have been imported into Hugo raw content under `_hugo/content/research/` while preserving public URLs such as `/research/2026/07/11/learn-claude-code-agent-loop-report/` and `/research/fde/`.

The one-time importer is:

```bash
./scripts/import-research-to-hugo.py
```

The importer uses `layout: "raw"` so each historical Research page keeps its original HTML, inline styles, and page-specific behavior. New Research pages can either use the same raw layout for custom pages or move to a shared Hugo research template later.
